# ONİ optional model packages

This repository distributes optional ONİ voice model packages and their license notices. It contains no ONİ application source, account data, service credentials, or private signing keys.

Advanced voice packages are downloaded by ONİ only when the user selects the supported optional voice engine. Published release assets use the documented ONİ encrypted distribution container; installation authorization is handled separately by the app.
